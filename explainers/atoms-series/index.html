⚛️ ML Math Atoms

16 narrated video lessons · 3.2 hours · made by David R. · davidramirezj.com

The idea: all the math of machine learning is built from 16 atoms. Each video teaches one atom with pictures, at least two worked examples, a "try it yourself" pause, and a real Python demo. Watch them in order — each one uses only the videos before it.

Every atom comes from one of 5 axioms: A linearity, B inner product, C local linearity, D probability rules, E learning = optimization. See the atoms → molecules map.

📖 Glossary — 52 terms

Every new term, with the video that teaches it.

TermMeaningVideo
activation functionThe nonlinearity applied to every output number of a layer, before the next layer.16 Activation function
basisA linearly independent set of vectors that spans the whole space.03 Basis & rank
chain ruleThe slope of a composition is the product of the slopes: dy/dx = dy/du · du/dx.09 Chain rule
componentOne entry of a vector: the number in one position of the list.01 Vector
compositionPutting one function after another: the output of f becomes the input of g, written g(f(x)).09 Chain rule
conditional probabilityThe probability of y when we already know x: p(y | x) = p(x, y) / p(x).12 Probability distribution
cosine similarityThe dot product divided by the two lengths: the cosine of the angle, from −1 to 1.05 Inner product
covarianceThe average product of the deviations of two variables. Its sign says if they move together.14 Variance & covariance
derivativeThe slope of a function at one point: the limit of rise over run as the run shrinks to 0.07 Derivative
dimensionThe number of vectors in any basis of a space.03 Basis & rank
distanceHow far apart two vectors are: the norm of their difference, x − y.06 Norm
dot productMultiply matching components and add: the result is one number.05 Inner product
expected valueThe probability-weighted average of the values: E[X] = Σ p(x)·x. The long-run average.13 Expected value
exponentialThe function e to the power x, with e ≈ 2.718: repeated growth that is always positive.10 exp & log
gradientThe vector of all partial derivatives. It points in the direction of steepest increase.08 Gradient
identity matrixOnes on the diagonal, zeros everywhere else. It changes nothing: I x = x.02 Matrix
image (range)All the outputs that the map can produce.04 Linear mapping
independenceKnowing one variable tells nothing about the other: p(x, y) = p(x) p(y).12 Probability distribution
inner productA rule ⟨x, y⟩ that turns two vectors into one number. It is symmetric, linear in each input, and positive.05 Inner product
JacobianThe matrix of all partial derivatives of a function with many outputs: row = output, column = input.09 Chain rule
kernel (null space)All inputs that the map sends to the zero vector.04 Linear mapping
limitThe value that an expression gets closer and closer to as h approaches a number (here 0).07 Derivative
linear combinationScale some vectors, then add them: a·u + b·v.01 Vector
linear independenceNo vector in the set is a combination of the others. Only all-zero weights give the zero vector.03 Basis & rank
linear mappingA function f with f(a·u + b·v) = a·f(u) + b·f(v): it respects adding and scaling.04 Linear mapping
local linear approximationNear x, replace the curve by its tangent line: f(x+h) ≈ f(x) + f′(x)·h.07 Derivative
logarithmThe power you must put on e to get a number: ln y = x means e^x = y.10 exp & log
loss functionA rule that takes the label and the prediction and returns one number, never negative: how wrong the prediction is.15 Loss function
matrixA rectangular grid of numbers, arranged in rows and columns.02 Matrix
matrix multiplicationDoing one matrix after another. Entry (i, j) of AB: row i of A times column j of B, multiplied entry by entry and added.02 Matrix
meanThe average of values; for data: sum ÷ count. The expected value is the mean of a distribution.13 Expected value
nonlinearityA function that is not linear: it does not keep adding and scaling.16 Activation function
normA rule that gives the size (length) of a vector as one number that is never negative.06 Norm
optimizationFinding the input that makes a function as small (or as large) as possible.15 Loss function
orthogonalTwo vectors are orthogonal when their inner product is zero: they meet at a right angle.05 Inner product
outcomeOne possible result of an experiment, like heads or a roll of blue 3, green 4.11 Random variable
parameterA number inside a model that we can change, like a knob. Learning means choosing its value.15 Loss function
partial derivativeThe slope of a function when only one input moves and all the other inputs are frozen.08 Gradient
probability distributionThe complete list of the values of a random variable with their probabilities (or a density).12 Probability distribution
product ruleJoint = conditional × marginal: p(x, y) = p(y | x) p(x).12 Probability distribution
random variableA rule (a function) that gives each outcome of an experiment a number.11 Random variable
rankThe number of linearly independent columns of a matrix (it equals the number of independent rows).03 Basis & rank
ReLURectified linear unit: ReLU(z) = max(0, z). Keeps positive numbers, turns negative numbers into 0.16 Activation function
scalarAn ordinary single number, used to stretch, shrink or flip a vector.01 Vector
spanAll the vectors you can reach with linear combinations of a set of vectors.01 Vector
standard deviationThe square root of the variance. It is in the original units: a typical distance from the mean.14 Variance & covariance
sum ruleTo forget a variable, add over all its values. The result is a marginal, like p(rain).12 Probability distribution
transposeFlip a matrix over its diagonal: its rows become its columns.02 Matrix
unit vectorA vector whose norm is exactly 1. It keeps only a direction.06 Norm
varianceThe expected squared distance from the mean: a number for how spread out the values are.14 Variance & covariance
vectorAnything you can add to another of its kind and scale by a number, and still get the same kind of thing.01 Vector
vector spaceA collection where adding and scaling never take you outside it, and the usual rules hold.01 Vector

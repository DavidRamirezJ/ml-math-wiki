Backpropagation

Continues the 13 Oct session: neuron → activation → XOR → “where do the weights come from?” Today we open the box marked $\partial L/\partial w$.

Bottom line: Backpropagation is how a network finds out how much each weight is to blame for the error.

It runs the network forward once to get the error, and then it passes the blame backward, layer by layer, using the chain rule: multiply the small local rates together.

Then gradient descent uses that blame to fix each weight: $w \leftarrow w - \eta\,\dfrac{\partial L}{\partial w}$.

1. Where backprop fits — the training loop from last time

┌──────────┐ ┌──────────┐ ┌───────────────┐ ┌───────────┐ │ FORWARD │ → │ LOSS L │ → │ BACKWARD │ → │ UPDATE │ │ x → ŷ │ │ how wrong│ │ ∂L/∂w for │ │ w ← w−η·g │ │ │ │ │ │ EVERY weight │ │ │ └──────────┘ └──────────┘ └───────────────┘ └───────────┘ ↑ ▲ this is backprop │ └──────────────────── repeat many times ──────────────────┘

Last time you saw the loop: predict, measure the error, compute the gradient, update, repeat. Backpropagation is only step 3. It does not change any weight. It only answers one question for every weight: “if I nudge you a tiny bit, how much does the error move?” That number is the gradient $\partial L/\partial w$.

2. The intuition — a factory and its blame

Imagine a factory with 3 workers in a line. Worker 1 cuts the wood, worker 2 paints it, worker 3 packs it. At the end, the boss sees the box is wrong.

The boss does not ask everybody from scratch. The boss tells worker 3: “this much is wrong.” Worker 3 knows how their own work affects the box, and passes the blame to worker 2. Worker 2 does the same for worker 1.

Each worker only needs local knowledge: “how does my output change when my input changes?” The blame travels backward and nobody does the work twice.

The gear picture of the chain rule. Three gears are connected. When gear A turns 1 time, gear B turns 2 times. When gear B turns 1 time, gear C turns 3 times.

So when A turns 1 time, C turns $2 \times 3 = 6$ times. You multiply the rates. That is the whole chain rule:

$$\frac{dC}{dA} = \frac{dC}{dB}\cdot\frac{dB}{dA} = 3 \cdot 2 = 6$$
$\frac{dC}{dA}$
how fast C moves when A moves
$\frac{dC}{dB}$
the local rate of the last gear pair (3)
$\frac{dB}{dA}$
the local rate of the first gear pair (2)

3. Our tiny network

We use the smallest network that still has a hidden layer with ReLU, like your XOR network. One input, one hidden neuron, one output, and a loss:

$$z = w_1 x + b_1 \qquad h = \mathrm{ReLU}(z) \qquad \hat y = w_2\,h \qquad L = (\hat y - t)^2$$
$x$
the input number
$w_1,\ b_1$
weight and bias of the hidden neuron (the network learns them)
$z$
the hidden neuron's raw sum, before the activation
$h = \mathrm{ReLU}(z)$
the hidden neuron's output: $\max(0, z)$ — keep it if positive, else 0
$w_2$
the weight from the hidden neuron to the output
$\hat y$
“y-hat”: the network's prediction (the hat means “estimate”)
$t$
the target: the correct answer we wanted
$L = (\hat y - t)^2$
the loss: the squared error — always ≥ 0, and 0 only when the prediction is perfect

4. Step through it — forward, then backward

🎛️ Change the numbers (everything recomputes)

Try this: make $w_1$ negative so that $z < 0$. Then ReLU outputs 0, its slope is 0, and the blame for $w_1$ and $b_1$ becomes 0. That neuron cannot learn from this example — this is the “dead ReLU” problem.

5. Check that the gradient is real — the nudge test

The gradient is a prediction: “if you nudge $w_1$ by a tiny amount $\varepsilon$, the loss changes by about $\frac{\partial L}{\partial w_1}\cdot\varepsilon$.” Press the button and watch the nudge ripple through the chain. Each arrow multiplies by one local rate.

The product of the local rates on the arrows is exactly the chain rule. Backprop just computes it from the right (the loss) to the left (the weights):

$$\frac{\partial L}{\partial w_1} = \underbrace{\frac{\partial L}{\partial \hat y}}_{2(\hat y-t)}\cdot\underbrace{\frac{\partial \hat y}{\partial h}}_{w_2}\cdot\underbrace{\frac{\partial h}{\partial z}}_{\mathrm{ReLU}'(z)}\cdot\underbrace{\frac{\partial z}{\partial w_1}}_{x}$$
$\partial$
“partial”: a derivative where you move one thing and hold everything else still
$\frac{\partial L}{\partial w_1}$
how much L moves per unit of movement in $w_1$ — the blame of $w_1$
$\frac{\partial L}{\partial \hat y} = 2(\hat y - t)$
slope of the squared error; negative means “the prediction is too small”
$\frac{\partial \hat y}{\partial h} = w_2$
because $\hat y = w_2 h$, moving $h$ by 1 moves $\hat y$ by $w_2$
$\mathrm{ReLU}'(z)$
slope of ReLU: 1 if $z > 0$, 0 if $z < 0$ (a gate: pass the blame, or block it)
$\frac{\partial z}{\partial w_1} = x$
because $z = w_1 x + b_1$, moving $w_1$ by 1 moves $z$ by $x$
$\underbrace{\ \cdot\ }_{\text{text}}$
the brace just labels what that factor equals

6. Why “backward”? The reuse trick

Look at the gradients for $w_1$ and $b_1$:

$$\frac{\partial L}{\partial w_1} = \color{#c2410c}{\frac{\partial L}{\partial z}}\cdot x \qquad\qquad \frac{\partial L}{\partial b_1} = \color{#c2410c}{\frac{\partial L}{\partial z}}\cdot 1$$

They share the orange part, $\partial L/\partial z$. Backprop computes it one time and reuses it. In a real network, every layer reuses the blame that came from the layer above it.

Naive way

For each weight, write its own long chain and compute it from scratch. With $N$ weights, you repeat almost the whole network $N$ times. GPT-2 has about 124 million weights — that means ~124 million passes. Impossible.

Backprop

One forward pass, then one backward pass. You get all $N$ gradients for roughly the cost of 2–3 forward passes. That is why deep learning is possible at all.

7. Train it live

Now use the gradients. Each step = forward → backward → update with $w \leftarrow w - \eta \cdot \partial L/\partial w$. Watch the loss go down.

The chart shows the loss L after each step. It drops fast at first and then slowly, because the gradient gets smaller as the prediction gets close to the target.

8. The same thing for real layers (matrices)

Show the matrix form — the formula used in real code

A real layer is $\mathbf h = \sigma(W\mathbf x + \mathbf b)$ (you saw this on 13 Oct). Call the incoming blame $\boldsymbol\delta = \partial L/\partial \mathbf z$. Then backprop for one layer is just three lines:

$$\frac{\partial L}{\partial W} = \boldsymbol\delta\,\mathbf x^{\top} \qquad \frac{\partial L}{\partial \mathbf b} = \boldsymbol\delta \qquad \boldsymbol\delta_{\text{prev}} = \left(W^{\top}\boldsymbol\delta\right)\odot\sigma'(\mathbf z_{\text{prev}})$$
$\boldsymbol\delta$
“delta”: a vector with the blame of each neuron's raw sum $z$ in this layer
$\mathbf x^{\top}$
the input vector turned on its side (transpose), so $\boldsymbol\delta\,\mathbf x^{\top}$ is a full matrix: blame of neuron $i$ × input $j$
$W^{\top}\boldsymbol\delta$
send the blame backward through the same weights, with the matrix transposed
$\odot$
multiply element by element (one neuron at a time)
$\sigma'(\mathbf z)$
slope of the activation at each neuron — for ReLU, a 0/1 gate

Compare with our tiny network: $\partial L/\partial w_1 = \delta\cdot x$ and $\partial L/\partial h = w_2\cdot\delta$. Same pattern, just with numbers instead of matrices.

In PyTorch you never write this: loss.backward() does it for every weight, and optimizer.step() does the update.

9. Check yourself

In summary

  • Backprop computes the blame (gradient) of every weight; gradient descent then uses it to update the weights.
  • Forward pass: compute and remember every value. Backward pass: start at $\partial L/\partial \hat y$ and multiply local rates going left (chain rule).
  • The trick is reuse: each layer reuses the blame from the layer above, so all gradients cost about one extra pass.
  • ReLU's slope is a gate (1 or 0): if a neuron's $z < 0$, no blame passes through it.

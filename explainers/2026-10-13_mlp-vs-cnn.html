MLP vs CNN

Multilayer Perceptron vs Convolutional Neural Network · ML-math wiki explainer · 2026-10-13

The short version: an MLP looks at the whole input at once. A CNN looks at small pieces of it, one at a time, using the same pattern detector everywhere.

The surprising part: a CNN is really just an MLP with some rules added. It isn't more powerful. It's a leaner MLP that's built for data where neighbours matter.

0 · The story in plain words

The MLP

Picture an image of 28×28 pixels. An MLP first flattens it into one long list of 784 numbers. Then every neuron in the next layer gets wired to all 784 of them, and every wire has its own weight to learn.

That has two downsides. It's huge: 100 neurons already means about 78,500 weights. It forgets the layout: once the image is flattened, the network has no idea which pixels were next to each other. If a cat moves 10 pixels to the right, the MLP basically sees a brand-new input and has to learn it again.

The CNN

A CNN takes a tiny window, usually 3×3 pixels, called a filter. The filter holds just 9 weights. It slides across the image, and at each spot it asks: "does this little patch look like my pattern?" The pattern might be an edge, a corner, or a patch of texture.

The trick is that the same 9 weights are reused at every position. So it stays tiny: 32 filters cost only 320 weights, whatever the image size. And it finds things anywhere: a filter that learned to spot an eye will spot it in any corner. Move the cat, and the output just moves along with it.

🔍 An analogy: the MLP is like reading a page by staring at every letter at once and memorizing where each one sits. The CNN is like running a magnifying glass over the page with one question in mind: "is there an 'e' here?" The question stays the same wherever you look.

2 · The formulas, symbol by symbol

Here's the same idea written in math. Don't worry if it looks dense. Each symbol is explained right below it.

MLP layer

$$\mathbf{h} = \sigma(\mathbf{W}\mathbf{x} + \mathbf{b})$$
$\mathbf{x}\in\mathbb{R}^{n}$
the input, a list of $n$ numbers. "$\in\mathbb{R}^n$" reads as "is a list of $n$ real numbers".
$\mathbf{W}\in\mathbb{R}^{m\times n}$
the weight matrix, a table with $m$ rows and $n$ columns. Every single entry is learned on its own.
$\mathbf{W}\mathbf{x}$
multiply the table by the input: each neuron takes one row of $\mathbf{W}$, multiplies it with all of $\mathbf{x}$, and adds it up
$\mathbf{b}\in\mathbb{R}^{m}$
the bias, a small extra number for each neuron
$\sigma(\cdot)$
the activation, a simple squash applied to each value. For example, ReLU, $\max(0,z)$, turns negatives into 0.
$\mathbf{h}\in\mathbb{R}^{m}$
the output, one value per neuron ($m$ of them)

If you zoom in on just one neuron, number $i$:

$$h_i = \sigma\Big(\sum_{j=1}^{n} W_{ij}\,x_j + b_i\Big)$$

$\sum_{j=1}^{n}$ means "add this up for $j = 1, 2, \dots, n$". In other words, neuron $i$ looks at every input.

Convolution layer (2-D)

$$h_{i,j} = \sigma\Big(\sum_{u=0}^{k-1}\sum_{v=0}^{k-1} K_{u,v}\; x_{i+u,\,j+v} + b\Big)$$
$x_{i,j}$
the pixel at row $i$, column $j$. The image stays a grid; nothing gets flattened.
$\mathbf{K}\in\mathbb{R}^{k\times k}$
the filter (also called a kernel), a small $k\times k$ grid of weights, often $3\times 3$
$\sum_u\sum_v$
add up over the little patch only, not the whole image
$x_{i+u,\,j+v}$
the pixels inside the patch that starts at $(i,j)$
$b$
a single bias, shared by every position
$h_{i,j}$
the output at position $(i,j)$. All of these together form the "feature map".

Here's the key detail: $\mathbf{K}$ has no $i$ or $j$ in it. It doesn't care where it is. The same weights get used at every position, and that's what people call weight sharing.

A small footnote: strictly speaking this is cross-correlation, because true convolution flips the filter first. Deep-learning libraries call it convolution anyway, and since the weights are learned, the flip doesn't matter.

4 · A convolution is a special matrix

This is the part that ties it all together. Take a small 1-D input of 6 numbers that produces 4 outputs, and write out each layer's weight table $\mathbf{W}$ (4×6) side by side.

MLP: 24 free weights

Every cell is its own number to learn.

Conv (kernel size 3): 3 free weights

Mostly zeros, because each output only sees its neighbours. And each diagonal repeats the same weight, because the filter is shared. Mathematicians call this shape a Toeplitz matrix.

So both layers do the exact same thing, $\mathbf{W}\mathbf{x}$. The only difference is the rules on $\mathbf{W}$. Fewer numbers to learn means the CNN needs less data and is less likely to memorize noise, as long as those rules actually fit your data.

ParametersGrow with input size × layer widthGrow with kernel size × number of filters only
Best forTables of data (age, income, credit score…) where column order means nothingImages, audio, time series: anything where nearby values belong together
Typical layer stackDense → ReLU → Dense → …Conv → ReLU → Pool → … → Flatten → Dense (an MLP head)
TrainingSame for both: a loss, backpropagation (chain rule), and gradient descent. In a CNN, the gradient of a shared weight is the sum of its gradients at all positions.
🔴 Expert notes
  • Universal approximation: an MLP with one hidden layer and enough neurons can approximate any continuous function on a compact set (Cybenko 1989; Hornik 1991). So CNNs are not "more powerful" in principle. They are more efficient for grid data: fewer parameters and better generalisation.
  • Equivariance, formally: let $T_s$ shift a signal by $s$. Convolution commutes with shift: $\mathbf{K} * (T_s\mathbf{x}) = T_s(\mathbf{K} * \mathbf{x})$. A dense $\mathbf{W}$ commutes with every shift only if it is a (circulant) convolution matrix.
  • Spectral view: circulant matrices are diagonalised by the discrete Fourier transform. So a convolution is a multiplication in the frequency domain (convolution theorem).
  • Multi-channel: real conv layers use $\mathbf{K}\in\mathbb{R}^{C_\text{out}\times C_\text{in}\times k\times k}$: each output channel sums over all input channels. Parameters: $C_\text{out}(C_\text{in}k^2+1)$.
  • Special case: a 1×1 convolution is an MLP applied independently to each pixel's channel vector.

7 · Check yourself

In summary

  • An MLP connects everything to everything. A CNN slides one small, reusable filter over the input.
  • That makes a CNN much smaller, and it can recognize a pattern no matter where it shows up.
  • Under the hood, both compute $\sigma(\mathbf{W}\mathbf{x}+\mathbf{b})$. The CNN just puts rules on $\mathbf{W}$: mostly zeros, plus repeated weights.
  • Use an MLP for tables and a CNN for images, sound and other grid-like data. Many real networks use both: a CNN pulls out features, then a small MLP makes the final call.
